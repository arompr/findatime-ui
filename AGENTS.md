# AGENTS.md

## What this application is

**findatime-ui** is the frontend for the Findatime event-scheduling product
(see `findatime-api`). It currently exposes a single homepage where users can:

- **Join an event** by entering its public code, then confirming their name and
  the event's passcode.
- **Create an event**, receiving a public code + passcode to share.

## Tech stack

- **Vite + React 18 + TypeScript** (SPA).
- **TanStack Router** (file-based routing with code-generated route tree).
- **TanStack Query** for server state / mutations.
- **Tailwind CSS** for styling.
- API calls via `@arompr/findatime-typescript-client` (GitHub Packages).

## Project layout

```
src/
  main.tsx                App entry: QueryClient + RouterProvider
  routeTree.gen.ts        Generated by @tanstack/router-plugin (do not edit)
  routes/                 File-based routes (__root.tsx, index.tsx -> /)
  lib/                    API adapter, guestId, error mapping
    api.ts                Configures OpenAPI.BASE + public-id-first wrappers
    guestId.ts            Stable per-browser UUID in localStorage
    errors.ts             ApiError -> user-friendly message mapping
  features/home/
    HomePage.tsx          Smart component (state + queries/mutations)
    hooks.ts              TanStack Query hooks (event lookup + create/join mutations)
    components/           Dumb, presentational components
      ui/                 Reusable primitives (Button, TextInput, Field, Modal, ...)
```

## Smart/dumb architecture

- **Smart** components (`HomePage.tsx`) own hooks, state, and API access; they
  pass data and callbacks down as props.
- **Dumb** components (`features/home/components/**`) are purely presentational:
  props in, events out. No API imports, no hooks (local input state is fine).

## API access — public-id first

All API calls go through `src/lib/api.ts`. The backend currently joins via the
internal event id, but `getEventByPublicId` resolves a public code to its id.
`joinByPublicId` hides this by resolving the id then calling `joinEvent`. When
the backend switches `JoinEvent` to accept the public id directly, update only
`joinByPublicId` — the rest of the UI is unaffected.

The base URL comes from `VITE_API_URL` (default `http://localhost:5263`).

## Conventions

- 2-space indentation, double quotes, semicolons (see `.editorconfig`).
- Path alias `@/` maps to `src/`.
- Use named exports for components and functions.
- Tailwind utility classes only; keep styling sober and minimal.
- No comments unless they clarify non-obvious behavior.

## Commands

```bash
npm install          # requires a GitHub token in ~/.npmrc (see README) for the typescript client
npm run dev          # dev server on :5173
npm run build        # typecheck + production build
npm run lint         # typecheck only

make container       # build the Podman image (mounts ~/.npmrc as a secret)
make container-dev   # run the image at :8080 (API calls go browser -> :5263)
```
